## 📜 Sobre o Projeto

Este projeto é um portfólio focado em unir diversas áreas do Front-end com animações 3D. Ele foi desenvolvido para mesclar a estética clássica de grandes franquias de games (como **Resident Evil**, **The Legend of Zelda** e **Kingdom Hearts**) com as tecnologias mais modernas de desenvolvimento web.

O objetivo principal foi dominar a integração entre **React** e **Three.js**, garantindo uma experiência imersiva, divertida e visualmente impactante, sem abrir mão da performance e otimização.

## Diferenciais Técnicos

* **Performance:** Otimização de malhas (meshes) e texturas para garantir fluidez em diversos dispositivos.
* **Identidade Visual Customizada:** Logo exclusiva em SVG e paleta de cores *dark* com detalhes em neon.
* **Responsividade:** Interface adaptada tanto para monitores Ultra-Wide quanto para dispositivos móveis.
