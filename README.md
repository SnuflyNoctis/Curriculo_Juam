# João Portfolio - Web 3D Experience
 
> **Access now:** [https://jao-dev.web.app](https://joao-dev-portfolio.web.app/)

## About the Project:

This project is a portfolio focused on merging various Front-end areas with 3D animations. It was developed to blend the classic aesthetic of major gaming franchises (such as **Resident Evil**, **The Legend of Zelda**, and **Kingdom Hearts**) with the most modern web development technologies.

The main goal was to master the integration between **React** and **Three.js**, ensuring an immersive, fun, and visually impactful experience, without compromising performance and optimization.
